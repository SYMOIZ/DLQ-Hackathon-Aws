Runs in your account

The agent and Decider run on your machine. SQS, S3 and Bedrock are the only AWS services, all in one account and region, with no always-on compute. Calls to Bedrock are capped per run and logged.

{{ d.n }}{{ d.p }}{{ d.s }}

Reusable pattern

"Failed-Message Recovery": one question, five options, a three-band confidence policy and a hook that runs before any destructive queue action. For a new message source, change only the state builder and thresholds.

patterns/failed_message_recovery/
├─ question.py   # typed question + 5 options
├─ state.py      # SQS, EventBridge, Kinesis, Step Functions
├─ policy.py     # thresholds + safety rules
├─ hook.py       # runs before redrive / delete
└─ README.md
